# SkillFlow baseline 实现范围（2026-10-13）

本表的六个 baseline 是统一 Harbor / Terminus 执行器下的**文本适配实现**，不是六篇原论文完整系统的复现。历史标签对应下表的更新机制；阅读主表时必须同时引用本说明。`protocol.json` 和历史正式分数在本轮工程修复中保持冻结。

| 主表标签 | 实际实现 | 未实现的范围 |
|---|---|---|
| ExpeL | 每题反思生成跨任务 insight，追加到有界文本记忆 | 原论文完整经验采样、检索和训练流程 |
| AWM | 仅通过题提取有序 workflow，失败题不更新 | 原版工作流发现、执行集成和检索系统 |
| ReasoningBank | 对成败生成 reasoning memory，追加文本 | 原版 memory 检索、构造和并行试验机制 |
| SkillRL | 失败题提取 general/family/task 层级文本 skill | 原论文强化学习训练和策略更新 |
| CoWork-X | 反思重写共享文本 skill library，可删除旧行 | 原版完整协作或学习基础设施 |
| RSEA | 提出替代上下文，第二题起用**当前同一道题**额外回放；奖励不下降才保留 | 独立 held-out 验证集；原版完整 RSEA 系统 |

所有方法使用相同做题执行器和模型配置；额外反思使用同一 DeepSeek 配置，文本预算为 6000 字符。RSEA 的选择回放不替换正式 reward。不同方法的更新条件和额外调用量不同，不能把文本机制比较解释为原论文系统在等训练预算下的排名。

2026-10-13 修复的工程问题包括：反思改读真实判分结果和执行动作，避免日志前缀挤掉失败信息；过长单条记忆保留有界内容；重写时提供全部保留记忆；反思失败保留既有 carry；重试累计作业和调用成本；无效结果进入独立错误记录而非正式主表；并发最多 4，磁盘检查失败或低于 6GB 时停止。详细验证见本轮质量修复报告。

这些修改修复现有适配实现，不构成新的论文级复现。未重跑历史模型、未重评历史主表、未修 Janus 系统、未开放 gate 或 locked。
