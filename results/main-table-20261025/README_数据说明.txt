本包仅包含用户确认的主表所使用数据，8方法×4benchmark，共32项汇总成绩、11568条逐题记录。
采用：SkillFlow历史第1轮Janus39/66；SQL现有1015题八方法正式成绩；Bash Janus153.28/200；τ候选A126/165（航空29/50、零售97/115）。七个对照保持原成绩。
不含其他提示词候选、失败尝试、基础设施错误、试点副本、进化第2—4轮及其他benchmark。正式计分中的有效零分保留，不能删除。
逐题CSV只保留计分及来源字段，不含轨迹、用户对话、参考答案、隐藏测试、目标数据库、API key或SSH凭据。
SQL和Bash是官方奖励平均值×100；SkillFlow和τ是reward>=1的通过率×100。四列仅统一显示单位，不代表相同计分定义。不计算跨benchmark平均分。
同一方法同一benchmark的题目ID唯一，八方法任务集合一致。所有32项按逐题数据重算并匹配用户确认的两位小数主表。
SQL原始总分使用完整精度，展示时平均奖励四舍五入至两位小数。原始收据中以pilot标记的前缀任务，如被原固定baseline全集账本采用，仍是该表的正式计分来源；本包仅导出全集实际使用的首个有效分，不额外附试点数据。
所有结果是各benchmark现有协议下的测量；SQL/Bash/τ与历史SkillFlow不构成一次统一协议重跑。重复使用开发集、单次测量等局限不因打包而消除。paperReady=false。
来源清单记录原文件位置及SHA256；仅用于溯源，不需要连接远程机器即可重算本表。manifest.sha256核对包内文件完整性。

显示精度：保留用户确认表原有的浮点格式化两位小数口径；极小的0.005边界会受浮点表示影响。逐题原始奖励及完整精度奖励总和保留，可另按明确的十进制舍入规则重排；本包不悄悄修改已确认表。运行“核验主表.py”可离线复算32项显示成绩。
